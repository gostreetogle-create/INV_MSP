# Inventor Pult

Пульт управления Autodesk Inventor 2027 через COM-мост — приложение с кнопками для рутинных
операций (создание деталей по вашей схеме обозначений, iLogic-правила, параметры) плюс
MCP-сервер, дающий Claude тот же доступ к Inventor во время совместной разработки.

## Структура репозитория

```
app/            исходный код (Python + HTML/CSS/JS)
  core.py         COM-мост к Inventor — вся автоматизация в одном месте
  webview_app.py  оконное приложение (pywebview) поверх core.py — это и есть «Пульт»
  mcp_server.py   тот же core.py, но как MCP-инструменты для Claude
  ui/index.html   интерфейс пульта
  tools/          reflect.py / enum_lookup.py — безопасный способ узнавать сигнатуры
                  методов и константы Inventor API без риска сломать COM-подключение
  catalog.xlsx    справочник типоразмеров труб/листов и прочих данных для выпадающих
                  списков — открывается прямо в Excel кнопкой «Справочник» в пульте
  InventorPult.spec   готовый файл сборки для PyInstaller
docs/
  INVENTOR_NOTES.md   всё, что узнали про Inventor COM API: рабочие рецепты, грабли,
                      константы — читать перед тем, как добавлять новую автоматизацию
  NAMING.md           схема обозначений деталей/модулей/изделий (PDM)
dist/
  InventorPult.exe          портативный exe — просто скопировать и запустить, без установки
  InventorPult-Setup.exe    настоящий установщик (мастер, ярлыки, автообновление старой версии)
installer/
  InventorPult.iss    исходник установщика (Inno Setup) — из него собирается Setup.exe
```

## Запуск готового приложения

Требования на целевом компьютере: только установленный и **запущенный** Autodesk Inventor 2027
(COM работает исключительно с локальным работающим экземпляром). Больше ничего ставить не нужно —
оба варианта ниже уже содержат Python и все зависимости внутри.

**Вариант А — установщик** (`dist/InventorPult-Setup.exe`): обычный мастер установки на русском,
ярлыки в Меню Пуск и (по желанию) на рабочем столе, значок «Удалить» в Пуске. Если запустить
установщик повторно (например, с новой версией) — старая версия сначала тихо удаляется, затем
ставится новая, без дублей и конфликтов. Не требует прав администратора.

**Вариант Б — портативный exe** (`dist/InventorPult.exe`): просто скопировать файл куда угодно
(хоть с флешки) и запустить — вообще без установки.

1. Запустить Inventor, открыть в нём проект.
2. Запустить приложение (любым из двух вариантов).

Справочник (`catalog.xlsx`) создаётся автоматически рядом с приложением при первом запуске, если
его там ещё нет — со стартовым набором данных (типоразмеры труб, толщины листов, крепёж, цвета
покрытия, типовые наименования деталей). Правки в нём (через Excel) сохраняются между запусками.

## Пересборка установщика

Требуется [Inno Setup](https://jrsoftware.org/isdl.php) (бесплатен для некоммерческого
использования — см. примечание ниже). После пересборки `.exe` (см. «Разработка» ниже):

```bash
cd installer
ISCC.exe InventorPult.iss
```

Готовый файл — `installer/Output/InventorPult-Setup.exe`.

> **О лицензии Inno Setup**: сам инструмент сборки установщика бесплатен для личного/
> некоммерческого использования. При коммерческом использовании (для рабочего ПО, как в нашем
> случае) автор просит приобрести лицензию — добровольно, без технических ограничений на
> собранный установщик. Подробности: https://jrsoftware.org/isorder.php

## Разработка

```bash
cd app
pip install -r requirements.txt
python webview_app.py          # запустить пульт из исходников
```

Пересобрать `.exe` после изменений:

```bash
cd app
pyinstaller InventorPult.spec
```

Готовый файл появится в `app/dist/InventorPult.exe`.

## MCP-сервер (для разработки с Claude)

```bash
claude mcp add inventor -s user -- python "<полный путь>/app/mcp_server.py"
```

После перезапуска Claude Code сессии инструменты для управления Inventor появятся напрямую у
Claude — то же самое, что умеет `core.py`, но как вызываемые инструменты.

## Обозначения деталей (PDM)

Формат `0000.0000.0000` (изделие.модуль.деталь), номера вводятся вручную (проверка на дубли —
автоматическая). Подробности и правила — в [docs/NAMING.md](docs/NAMING.md).
